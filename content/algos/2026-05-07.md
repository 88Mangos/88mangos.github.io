# Problem Statement
You are given an integer array nums of length n.

You start at index 0, and your goal is to reach index n - 1.

From any index i, you may perform one of the following operations:
- Adjacent Step: Jump to index i + 1 or i - 1, if the index is within bounds.
- Prime Teleportation: If nums[i] is a prime number p, you may instantly jump to any index j != i such that nums[j] % p == 0.

Return the minimum number of jumps required to reach index n - 1

Instead of doing DP, which table fills from n-1 to 0 without going back a second time, the intended approach was BFS.

```python
from collections import deque, defaultdict

class Solution:
    def minJumps(self, nums: list[int]) -> int:
        n = len(nums)
        if n <= 1:
            return 0

        # 1. Standard Prime Sieve (up to max value in nums)
        max_num = max(nums)
        is_prime_bit = [True] * (max_num + 1)
        is_prime_bit[0] = is_prime_bit[1] = False
        for p in range(2, int(max_num**0.5) + 1):
            if is_prime_bit[p]:
                for i in range(p * p, max_num + 1, p):
                    is_prime_bit[i] = False

        # 2. Map primes to indices of their multiples
        # We only care about primes that actually appear as a nums[i]
        primes_in_nums = {x for x in nums if x > 1 and is_prime_bit[x]}
        prime_to_indices = defaultdict(list)
        
        for i, val in enumerate(nums):
            # For each prime p in our set, if val is a multiple, record it
            # To stay efficient, we only check primes that are factors of val
            temp = val
            d = 2
            while d * d <= temp:
                if temp % d == 0:
                    if d in primes_in_nums:
                        prime_to_indices[d].append(i)
                    while temp % d == 0:
                        temp //= d
                d += 1
            if temp > 1 and temp in primes_in_nums:
                prime_to_indices[temp].append(i)

        # 3. BFS
        queue = deque([(0, 0)])  # (current_index, distance)
        visited = {0}
        visited_primes = set()

        while queue:
            curr, dist = queue.popleft()

            if curr == n - 1:
                return dist

            # Adjacent Step: i+1 and i-1
            for neighbor in [curr - 1, curr + 1]:
                if 0 <= neighbor < n and neighbor not in visited:
                    visited.add(neighbor)
                    queue.append((neighbor, dist + 1))

            # Prime Teleportation
            p = nums[curr]
            if p in primes_in_nums and p not in visited_primes:
                visited_primes.add(p)
                for target_idx in prime_to_indices[p]:
                    if target_idx not in visited:
                        visited.add(target_idx)
                        queue.append((target_idx, dist + 1))

        return -1
```

# Self-Reflection

## Algo Design Technique
I mean it's just a shortest path algo. Each jump is just an unweighted edge, edges must be `(i, i+1)`, `(i, i-1)`, or `(i, j)` with the prime-check. Then it's just a BFS from vertex `n-1` to `0`, or vice versa. Get the length of that path and we're done. Honestly could be an OK 210 question...

## What I did well
I quickly figured out that computing the valid jumps on-the-fly was costly, and it was smart to precompute the successors (and eventually, just the predecessors) ahead of time using the `isPrime` function.
